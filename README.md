# 🎬 ProCut Studio

A lightweight, single-file mobile-first web video editor inspired by **CapCut Mobile**.  
**Developed by:** `ashfak arya`

## ✨ Features

- **CapCut-Style Mobile UI**: Top canvas preview, scrollable multi-track timeline, and bottom slide-up tool panels.
- **Multi-Track Timeline**: Drag to move clips, split at playhead (`S`), duplicate, and delete.
- **Media Support**: Import videos, images, GIFs, and audio files directly from your device.
- **Text & Stickers**: Custom fonts, colors, backgrounds, and 60+ built-in emoji stickers.
- **Filters, Effects & Color Grading**: 10+ filter presets, Glitch/VHS/Blur effects, and manual color sliders.
- **Transform & Keyframes**: Crop, scale, rotate, flip, and animate properties over time using keyframes (`◆`).
- **Real Video Export**: Renders timeline frames and audio directly into a downloadable `.webm` video file with developer credits (`ashfak arya`).

## 🚀 Quick Start

1. Extract this ZIP archive.
2. Open `index.html` directly in any modern browser (Chrome, Edge, Safari, or mobile browsers).
